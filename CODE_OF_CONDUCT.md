# Overview

Zorvax Core is committed to building a professional, collaborative and respectful development environment.

This Code of Conduct defines the standards expected from all contributors, maintainers and community members participating in the project ecosystem.

The objective is to encourage:
- healthy collaboration
- constructive communication
- professional behavior
- long-term community growth

---

# Community Principles

The Zorvax Core community is built around the following principles:

| Principle | Description |
|---|---|
| Respect | Professional and constructive interaction |
| Collaboration | Open and productive teamwork |
| Integrity | Honest and responsible participation |
| Inclusivity | Welcoming environment for contributors |
| Professionalism | Mature and respectful conduct |

---

# Expected Behavior

Community members are expected to:

✔ Treat others respectfully  
✔ Provide constructive feedback  
✔ Maintain professional communication  
✔ Respect different opinions and experiences  
✔ Focus on collaboration and problem solving  
✔ Help maintain a healthy development environment  

---

# Unacceptable Behavior

The following behavior is not tolerated within the project ecosystem:

✘ Harassment or discrimination  
✘ Personal attacks or insults  
✘ Toxic or hostile behavior  
✘ Spam or disruptive communication  
✘ Malicious contributions  
✘ Intentional misinformation  
✘ Public or private harassment  
✘ Any form of abusive conduct  

---

# Development Discussions

Technical disagreements are natural during development.

However, contributors are expected to:
- discuss ideas respectfully
- focus on technical arguments
- avoid personal conflicts
- prioritize project quality over ego

The goal is to improve the framework collaboratively.

---

# Contribution Ethics

All contributions should be made in good faith and aligned with the project philosophy.

Contributors should avoid:
- intentionally harmful code
- malicious backdoors
- exploit-oriented behavior
- code plagiarism without attribution
- disruptive pull requests

---

# Security & Responsible Disclosure

Security vulnerabilities should be reported responsibly and privately whenever possible.

Contributors should never:
- publicly expose critical vulnerabilities before fixes
- intentionally exploit project weaknesses
- distribute malicious modifications

Responsible disclosure helps protect the ecosystem and its users.

---

# Enforcement

Project maintainers reserve the right to take appropriate action when violations occur.

Actions may include:

- warnings
- content removal
- temporary restrictions
- permanent bans from project spaces

Enforcement decisions are intended to preserve the integrity and professionalism of the community.

---

# Scope

This Code of Conduct applies to:

- GitHub repositories
- discussions
- issues
- pull requests
- documentation
- official community spaces
- collaboration channels

---

# Community Goal

Zorvax Core aims to create more than a traditional FiveM project.

The objective is to build a professional infrastructure ecosystem where developers can collaborate, learn and contribute within a respectful and organized environment.

A strong community is built through professionalism, collaboration and mutual respect.

---

# Final Notes

By participating in the Zorvax Core ecosystem, contributors agree to follow the standards described in this document.

These guidelines exist to ensure a productive and sustainable environment for everyone involved in the project.
