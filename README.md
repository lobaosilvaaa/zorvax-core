# 🚀 About

Zorvax Core is a lightweight and modular framework focused on:

- Performance First
- Clean Architecture
- Modular Systems
- Developer Friendly APIs
- Optimized Resources
- Modern UI/UX

Built for scalable FiveM roleplay environments.

---

# 📦 Ecosystem

| Repository | Description |
|------------|-------------|
| `zvx_core` | Core framework systems |
| `zvx_hud` | HUD and interface |
| `zvx_inventory` | Inventory system |
| `zvx_phone` | Phone system |
| `zvx_target` | Interaction system |
| `zvx_garages` | Garage system |
| `zvx_vehicles` | Vehicle assets |
| `zvx_maps` | Maps and MLOs |
