## Overview

Zorvax Core is a next-generation FiveM framework focused on performance, modularity and long-term scalability.

Designed from the ground up with a clean and independent architecture, Zorvax aims to provide a professional ecosystem for serious roleplay communities and custom server infrastructures.

Unlike traditional edited frameworks, Zorvax Core follows a framework-oriented philosophy centered around:

- maintainability
- performance optimization
- secure networking
- modular systems
- scalable architecture
- clean development standards

## Philosophy

Zorvax Core is not intended to be another modified roleplay base.

The project was created with the objective of building a modern, scalable and independent framework capable of supporting high-quality roleplay experiences without relying on legacy architecture limitations.

Every system is designed around three core principles:

- Performance
- Security
- Scalability

---

## Architecture

The framework architecture is designed to be:

| Principle | Description |
|---|---|
| Modular | Independent and isolated systems |
| Event-Driven | Optimized communication flow |
| Secure-by-Design | Validation-focused infrastructure |
| Scalable | Built for long-term expansion |

## Development Standards

Zorvax Core follows strict development standards to ensure consistency, maintainability and performance across the entire ecosystem.

### Standards Include

- snake_case naming convention
- isolated module architecture
- minimal dependency coupling
- server-side validation
- clean event structure
- organized folder hierarchy
- optimized networking flow

More information can be found inside the `/docs` directory.
